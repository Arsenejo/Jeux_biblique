# Périmètre

Le dépôt sert deux expériences :

- Défi Jean, quiz statique Louis Segond 1910, toujours vérifié par `verifier-questions.js`.
- Le Grand Pèlerinage, application Vite/React déployée par Vercel (`grand_pelerinage_v1`).

Public : lecteurs et groupes d'église, d'abord sur téléphone, jouable hors ligne après le premier chargement.

Hors périmètre de cette stabilisation : le texte intégral des 66 livres, et un classement impossible à falsifier sans fonction serveur qui valide chaque étape.
